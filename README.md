# Vanod

The public Vanod product website and browser-based paper-trading preview.

**Website:** https://calibg.github.io/vanod/

## Current experience

- Public BTC/USD, ETH/USD and SOL/USD prices, OHLC charts and read-only order-book snapshots from Coinbase Exchange, refreshed approximately every 30 seconds.
- A local paper-trading account with 10,000 virtual USD; market orders, limit-order reservation, cancellation and local history.
- Vanod's approved wordmark, Forward V identity and confirmation animation.
- Slate magnetic hardware-wallet industrial-design concept and product roadmap.

This is a product preview. It accepts no real funds, sends no real orders and does not manage private keys. Limit orders do not auto-match. Mobile applications and hardware integration are in development.

## Deployment

Only the contents of `public/` are published using GitHub Pages Actions. The repository contains the website's exported static files; private project material, app development files and reference repositories are not included.

## Privacy

Paper-account data stays in this browser's local storage and is separate from the mobile prototype. Market requests go directly to Coinbase's public service. GitHub Pages processes visitor information as described by GitHub's privacy policy. See the website's product and privacy page for details.
