产品与隐私说明

更新于 2026 年 10 月 28 日

Vanod 当前是开发中的交易与硬件钱包产品。网站只提供公开行情和本机模拟交易，不接收真实资金，不执行真实交易。

你现在可以体验什么

  • 读取 Coinbase 公共 BTC/USD、ETH/USD、SOL/USD 行情、K 线和盘口。
  • 使用 10,000 USD 初始虚拟资金体验市价买卖、限价挂单与撤单。
  • 查看本机模拟账户、冻结余额、历史订单和品牌确认动效。

行情约每 30 秒刷新，并非交易所推送级实时数据。连接失败会显示错误或旧数据。示例行情只有在你主动选择后启用，并明确标注。

模拟交易如何计算

模拟市价单以当前有效报价简化成交，不模拟真实盘口滑点、市场冲击或成交概率。模拟费率固定为 0.10%，按 USD 分向上取整，不代表 Coinbase 或其他交易所的真实费率。限价单仅挂单并冻结余额，支持撤单，当前不会自动撮合。

网页、移动开发版的模拟账户各自保存在对应浏览器或设备中，彼此不会同步。模拟记录不是资金凭证或链上交易记录。

Slate 硬件规划

Slate 采用薄型矩形的磁吸硬件钱包设计方向。计划采用独立屏幕和实体确认键，逐项展示网络、完整地址、金额及费用。

官网图片为工业设计概念图，尚未量产，也没有完成硬件安全认证。真实蓝牙通信、密钥管理、签名和链上广播仍在开发。磁吸仅表示物理吸附，不代表设备认证或授权成功。

客户端与真实交易

iPhone 与 Android 采用同一产品设计开发。目前处于开发阶段，尚未发布 App Store、Google Play、IPA 或 APK 安装包。正式发布后，这里将提供下载入口。

正式交易计划通过现有服务商的官方接口接入。当前没有真实账户登录、交易所 API Key 输入、充值、提现、借贷、杠杆或收益产品。公开行情和模拟结果不构成投资建议。

隐私与本地数据

官网由 GitHub Pages 托管。GitHub 会为安全目的记录访客 IP 地址，并处理提供服务所需的技术信息，具体以 GitHub 隐私声明 为准。

查看行情时，浏览器会直接访问 Coinbase 公共行情接口，因此该服务会收到连接所需的网络信息。Vanod 不随行情请求发送钱包私钥、交易所密钥或模拟订单。

网页模拟账户与订单保存在浏览器本地存储中。Vanod 当前没有用户后台、云端账户同步、广告追踪或主动埋点。浏览器本地数据并非加密冷存储，不应存放真实私钥或助记词。清除站点数据可能删除模拟记录。

网站不要求你输入真实身份、助记词、私钥或金融账户凭据。不要在项目反馈中提交这些信息。

项目反馈

你可以通过 GitHub 项目反馈 报告网站问题。反馈默认公开，请仅提供必要且不敏感的信息。
